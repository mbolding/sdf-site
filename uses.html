SDF
The Public Access UNIX System since 1987. It hosts this site, the phlog in gopherspace and the gemlog in Geminispace, and gives me a shell to ssh into.
rsync.net
Offsite storage over plain ssh, with ZFS snapshots to go back through.

This site

Hand-written HTML, one stylesheet and a small script for the themes, with no build step. Only the Mermaid page and a few old experiments load anything from elsewhere, their charting libraries. Each page stands on its own, and the toys keep your pictures and settings in your browser. The web clocks are the same idea, served from Cloudflare Workers.

Homemade Mac apps

All in the desktop_widget folder, built with swiftc and a shell script, no Xcode project.

For the small internet
Gopher Browser (gopher, Gemini, Spartan, finger), News Reader (Usenet), Relay Chat (IRC), SDF Post (the blog), Offsite (rsync.net).
Floating widgets
An analog clock and a word clock, Month Calendar, Dial Timer, Scratch Pad, Command Bar (a floating shell), Soma Player (SomaFM and tilderadio), and Widget Bar to open them all.
In the Dock and menu bar
Dock Clock, Dock Load (CPU and memory as rings), Server List.
Ordinary windowed apps
Map Browser, Markdown Editor, Text Extractor, DICOM Viewer, Stipple, Polyhedra.
